## 🌟 Project Overview

A modern **Event Ticket Booking Web Application** that allows users to explore events, register, and book tickets seamlessly.

Built using **HTML5, CSS3, and JavaScript**, this project demonstrates a complete front-end system with structured navigation and interactive UI.
